What this preview shows

Orange dashed boxes are unclipped planning regions, not credited material.

Side-view buttons look from the positive print axis toward the part, with print Z upward. They change only the camera. The Design axes indicator follows the pose and camera; these are the axes used by helper centre controls. A circled dot points toward you; a circled cross points away. Drag or use arrow keys in the viewer to orbit. Shading shows geometry, not stress or support requirements.

        1. Keep the saved draft and the exact orientation table together on your compute worker. The matching body mesh must be available in the adjacent part source checkout, or set SPOOL_RACK_ROOT to that checkout.
        2. Run this command in the project's Python environment, using paths to your files. PROFILE.3mf is an Orca-written project with the intended printer and material settings; an archived slice-evidence ZIP containing audit.3mf also works.
        The command uses the suggested download names. If your browser renames a duplicate, use its actual name. Replace PROFILE.3mf with your template path.
        fdmgen massing DRAFT.json --table TABLE.json --template PROFILE.3mf --out out/massing
        1. Check the exported geometry
        The exporter writes the project, a shell-only baseline and a report. Exit code 2 means a geometry check failed: inspect the report and revise the named helper. A written project alone does not mean its checks passed.
        2. Slice both projects
        • Helper project: out/massing/PART-POSE-massing.3mf
        • Shell-only baseline: out/massing/PART-POSE-massing-shell-only.3mf
        Use the same Orca build and printer, filament and process settings for both. Turn automatic arrangement and orientation off to preserve the exported pose. Save the corresponding toolpaths as project.gcode and shell-only.gcode, or substitute their actual paths below.
        3. Build the evidence bundle
        fdmgen evidence out/massing/PART-POSE-massing.json project.gcode shell-only.gcode --table TABLE.json --pose POSE_ID --out out/evidence
        Replace PART-POSE and POSE_ID with the exact exporter names and selected pose identifier. Save a draft to fill recognised identifiers here.
        This runs helper slice evidence, shell-check 0.3 and pose-bound bridge checks on the helper and shell-only slices. The evidence worker also needs the matching part source checkout (or SPOOL_RACK_ROOT for the bracket adapter), because shell and bridge checks load the body mesh. Exit code 2 records one or more FAIL results; inspect them. Exit code 1 means an error and no completed manifest. A zero exit code remains toolpath evidence, not physical qualification.
        4. Review the results
        In helper export review, load the saved draft and exporter report first. Then select out/evidence/evidence-bundle.json together with all five receipt JSON files in that folder. The review checks their fingerprints before displaying paired results.
